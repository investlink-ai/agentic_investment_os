# Agent Notes

- Read `README.md` completely before adding, moving, rejecting, consolidating, or deleting a note.
- Use the `manage-agent-notes` skill for lifecycle and ownership decisions and `prose-standard` for
  substantial note prose.
- Keep current behavior in its active document, schema, configuration, or code owner. Notes preserve
  reasoning and link to those owners.
- Match the filename date and lifecycle directory to the note's `Status:` line. Use relative links for
  repository sources and repair inbound links when a note moves or disappears.
- Preserve real alternatives, consequences, negative guarantees, and verification that guide future
  choices. Remove authoring-session narration, task checklists, and duplicated inventories.
- Maintain one English file only. Use Git history for deleted material; create no archive, translation,
  sidecar, manifest, or generated index.
